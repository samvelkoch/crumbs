# Пищевой Детектив: Медок и Пуся

Дневник питания, воды и кожных реакций в игровой форме для ребёнка и родителя.

- Single-file web app (`index.html`), без зависимостей и сборки.
- Все данные хранятся только в браузере на устройстве (`localStorage`); на сервер ничего не отправляется.

Запуск: открыть `index.html` в браузере или через GitHub Pages.
