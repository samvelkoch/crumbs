# crumbs — Пищевой Детектив: Медок и Пуся

Дневник еды, воды и кожи в игровой форме для ребёнка и родителя.

## Версии

| Папка | Что это |
|---|---|
| `app/` | **v2**, новая версия: PWA, Радар следов, дневник-календарь, отчёт для врача, зашифрованный бэкап |
| `index.html` | v1, исходная одностраничная версия (оставлена до решения) |

Сайт: `https://samvelkoch.github.io/crumbs/app/` (v2), `https://samvelkoch.github.io/crumbs/` (v1).

## v2: устройство

- Без сборки и зависимостей: ES-модули в `app/js/`, стили в `app/styles.css`.
- **Приватность.** Данные только в IndexedDB браузера. CSP в `index.html` запрещает любые запросы, кроме собственных файлов сайта: ни аналитики, ни внешних шрифтов. В репозитории нет данных.
- **Перенос между устройствами.** «Сохранить копию» шифрует данные паролем семьи (PBKDF2-SHA256 250k + AES-256-GCM, WebCrypto). «Загрузить копию» объединяет записи по id, свежая правка побеждает, удалённые не воскресают.
- **PWA.** `manifest.webmanifest` + `sw.js` (сначала сеть, без сети кэш). Ставится на iPhone/iPad через Safari → «На экран Домой», на Android через Chrome → «Установить».
- **Время.** Все дни считаются в Europe/Budapest (`app/js/dates.js`).
- **Радар** (`app/js/radar.js`). Для каждого замера кожи берутся продукты и улики за 1–48 ч до него. Сравниваются замеры «с продуктом» и «без», а гребневая регрессия даёт вклад продукта при прочих равных (клубника, которая просто часто попадала в дни с шоколадом, не становится подозреваемой). Порог: ≥ 3 замера и ≥ 2 дня. Семейства (всё молочное, пшеница, какао…) проверяются отдельно. Продукты, которые всегда шли вместе, помечаются как неразличимые.
- **Дела.** Эксперимент «N дней без продукта»: кожа в эти дни сравнивается с тем же числом дней до начала.
- **Маскоты** (`app/js/mascots.js`): SVG по фото игрушек, 5 эмоций.

## Запуск локально

```bash
npx http-server -p 8080 .   # затем http://localhost:8080/app/
node --test tests/*.test.mjs
```

ES-модули и service worker не работают с `file://`, нужен любой локальный сервер.
